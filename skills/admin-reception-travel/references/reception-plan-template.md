# 接待方案骨架与文案（演示数据虚构）

## 方案 Word 骨架

```
关于XX公司一行来访的接待方案
一、来宾概况
    单位：XX科技有限公司；人数：4（名单附后）；来访目的：年度合作洽谈；
    到达：11月6日（周五）G7XXX次 11:23到南站；离开：当日18:40。
二、接待级别与目标
    公司级接待。目标：完成合作框架协议签署并安排产线参观。
三、分组分工
    总协调：王琳（138****0001）｜会议室：陈默｜迎送车辆：司机老周（公司中巴）
    参观动线：生产部刘工｜材料：市场部｜餐饮住宿：行政前台｜应急：行政值班
四、行程总览（嵌行程表，或引用附件xlsx）
五、物料清单
    欢迎屏文案｜席卡4+我方3｜参观证8｜签字笔纸｜茶歇（忌口标注）｜
    协议文本2份｜相机与合影位
六、应急预案
    来宾晚点>30min：压缩参观段为一站，会议优先，告知领导调整出面时间
    雨天动线：A座连廊路线，备伞6把（处置：前台）
    医务：园区医务室位置+值班电话（按公司实际填）
```

## 文案模板

- 欢迎屏：`热烈欢迎XX公司各位领导莅临我司参观指导`（政府来访用「欢迎XX调研组莅临指导」；双方签约加 `暨合作框架协议签约仪式`）
- 席卡：姓名+职务，字号以1.5米外可读为准；客方按职务排序，面门为尊。
- 接送举牌：`欢迎XX公司一行` + 我方公司名。
- 短信/微信告知来宾（司机联系方式模板）：
  `X总您好，我司司机周师傅（电话【待确认】）将于11:10在南站南出站口举牌等候，车牌【待确认】。`

## 政府检查类差异点

- 必带：迎检资料盒（制度、台账、证照复印件）清单；陪同人员含对口业务部门负责人。
- 话术口径先由业务部门确认，行政只做流程与场地。
- 不安排与检查无关的参观与宴请。

## 应急预案四件套

迟到/行程压缩、恶劣天气、设备或车辆故障（备用车方案）、人员身体不适（医务点+就近医院）。每条 = 触发条件 + 处置动作 + 处置人 + 告知谁。
