# 接待方案与执行清单

```text
关于【单位/团队】来访的接待方案（草稿/已确认按实标注）
一、来宾与目的：单位、人数、已知名单，来访目标。
二、到离信息：绝对日期时间、时区、站点，信息来源与确认状态。
三、我方接待：总协调、对口部门、会谈/参观负责人；级别按公司制度。
四、行程总览：引用同一数据生成的行程附件，注明版本。
五、保障与物料：会议室容量、材料、车辆、席卡、餐饮、住宿（如需）。
六、权限与待确认：摄影、参观区域、忌口、联系方式与费用标准。
七、应急：触发条件、动作、负责人、告知对象、备用安排。
```

手机号、车牌、酒店、会议室只使用实际资料，缺失写【待确认】，不放仿真的掩码手机号充当联系人。人数与席卡、餐饮、车辆座位同步；参观生产区的许可与安环配合由责任部门确认。

## 文案

- 欢迎屏：`欢迎【来宾单位/团队】来访交流`，称谓沿双方确认口径。
- 接站牌：`【来宾单位/团队】＋【我方单位】`，避免公开不必要的个人信息。
- 告知模板：`您好，【日期时刻】由【接待人】在【具体位置】等候；联系方式【待确认】，车辆【待确认】。` 先出草稿，不等于已发送。

## 应急

| 场景 | 需写清的安排 |
| --- | --- |
| 到站晚点、会谈延误 | 可压缩段、不可移动窗口、通知人；改后重跑行程检查 |
| 雨雪/场地关闭 | 室内替代动线、接送位置、参观能否取消 |
| 设备/车辆故障 | 备机/备用车的确认状态及启用人 |
| 身体不适 | 已核实医务点/应急联系方式、陪同人；不编医疗结论 |

政府检查按实际检查要求备材料，不安排与检查无关的参观与宴请。不得依据职级自动推荐高规格礼品、宴请或待遇。
