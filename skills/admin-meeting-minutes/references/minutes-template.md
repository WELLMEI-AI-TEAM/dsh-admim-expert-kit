# 纪要模板与句式库（演示数据虚构）

## 纪要全文模板

```
XX公司2026年第4周例会 会议纪要
时　间：2026年10月27日（星期二）14:00—15:30
地　点：三楼第二会议室
主　持：王琳（总经理）
记　录：陈默（综合管理部）
参会人：（按姓氏笔画/部门顺序列名，注明职务）
请假人：李强（事假）

一、关于消防演练筹备
    会议指出，演练方案已通过属地消防支队预审。
    会议决定：11月6日15:00在园区A座开展疏散演练，综合管理部牵头，
    各部门负责人签到参加。
    → 行动项 A1：完成演练通知发布与签到表准备（责任：陈默；11月3日前；
      验收：全员通知送达率100%，签到表打印到位）

二、关于Q4办公用品采购
    会议听取了行政组关于采购预算的汇报。
    会议决定：按「先盘库后采购」执行，盘库数据以10月31日台账为准。
    → 行动项 A2：（同上五要素格式）

遗留问题：前台接待区改造预算未定，定于11月3日专题会审议。
```

## 常用句式

- 领起结论：会议决定 / 会议同意 / 会议要求 / 会议指出 / 会议听取了 / 经与会部门协商确定
- 转述共识（不落具体人）：与会认为 / 各部门一致表示
- 保留分歧：XX部门建议……，XX部门提出不同意见，会议决定另行专题研究
- 行动项句式：由＋责任部门/人＋在＋期限＋前完成＋事项＋，验收标准：＋可核查的一条

## 禁用与替换表

| 不写 | 改写为 |
| --- | --- |
| 尽快落实 | 2026年11月5日前完成 |
| 有关部门 | 实名部门（如：综合管理部） |
| 基本同意 | 会议同意，其中XX条款待预算确认后生效 |
| 大家讨论后认为 | 与会认为 |

## 不同会议类型的裁剪

- **周例会**：重行动项与上周完成情况对比（可加「上周A1完成情况：已完成/延期，原因…」一行制）。
- **专题会**：重决议与依据，背景节可长，句式用「会议审议并原则通过《XX方案》」。
- **协调会**：重职责边界，每条决议写清「主办＋协办＋接口人」。
