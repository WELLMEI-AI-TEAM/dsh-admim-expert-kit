# 纪要结构与来源标注

## 正式纪要骨架

```text
【会议名称】会议纪要
时间：【绝对日期、起止时刻、时区】
地点/线上平台：【已提供内容】
主持、记录、参会范围：【已提供内容；不猜请假原因】

一、【议题】
背景/事实：【核对过的原始内容】
讨论与建议：【注明建议、条件或分歧，非决议】
明确决议：【仅记录原文明确议定的事项】
关联行动：【A1等稳定编号】
来源定位：【原文段落/时间戳/材料页码】

二、行动项汇总
编号、事项、负责人、协助方、期限、验收标准、来源定位。
三、未决事项/分歧/下次安排（原文没有就省略）
```

短周会可压缩为“已定事项、待办、未决”，不必重复头部与正文。现有纪要只更新指定范围，保留历史编号。

## 措辞与证据

| 原材料 | 可以写 |
| --- | --- |
| “要不先试点，等领导确认” | 提议试点，尚待批准 |
| “同意方案，预算待财务核” | 方案获得有条件同意，预算待核，不能写全面获批 |
| “尽快完成” | 期限待确认（保留原文“尽快”），不能自行指定11月5日 |
| 明确“由陈某11月12日前交付报表” | 行动项列负责人、原定期限与交付内容 |
| 两段录音对时间说法相反 | 并列冲突来源，待确认；不能以最后一段自动覆盖 |

没有明确共识不写“与会一致认为”；来源是个人陈述时保留说话人，不把它写成组织事实。缺主持/记录不等于会议不能整理，只需标待确认或省略非必需字段。

## 长材料与版本

按议题建立事实/建议/决议/待办映射，再去重；不同议题同名任务不能只因文案相似合并。保留段落号或时间戳，行动项与正文引用一致。增量跟进按稳定ID匹配，同ID状态冲突列待核，禁止剪切历史来“清理”台账而不保留关联。
