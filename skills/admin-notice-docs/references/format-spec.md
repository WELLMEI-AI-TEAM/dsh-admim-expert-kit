# 排版细则（GB/T 9704 风格的行政可用版）

## 版面

- 页幅 A4（210×297mm）。边距：上 3.7cm、下 3.5cm、左 2.8cm、右 2.6cm。
- 行距：正文固定值 28 磅（约每面 22 行×28 字）。段落首行缩进 2 字符，不用空格凑。
- 页码：版心下外侧「— 1 —」（四号宋体），单页文件可省略。

## 版头区（正式红头文件才用；普通事务通知直接跳过本区）

自上而下：份号（左上，涉密才标）→ 密级★保密期限（左上）→ 紧急程度（左上）→ 发文机关标志（红色小标宋，居中）→ 发文字号（机关代字〔年份〕序号，居中或居左）→ 签发人（上行文才标，居右）→ 红色分隔线。
普通公司通知通常只保留：红头名称 + 分隔线，其余按公司发文制度留占位。

## 主体要素字体字号

| 要素 | 字体 | 字号 | 说明 |
| --- | --- | --- | --- |
| 标题 | 方正小标宋简体 | 二号(22pt) | 居中，可分1-2行，梯形/菱形排布，回行居中 |
| 主送机关 | 仿宋 | 三号(16pt) | 顶格，冒号结尾 |
| 正文 | 仿宋_GB2312/仿宋 | 三号 | 每段首行缩进2字符 |
| 一级标题「一、」 | 黑体 | 三号 | 不加粗也醒目，避免与正文字号相同出错 |
| 二级标题「（一）」 | 楷体 | 三号 | |
| 三级「1.」 | 仿宋加粗 | 三号 | |
| 附件说明 | 仿宋 | 三号 | 正文下空一行左空二字 |
| 发文机关署名/成文日期 | 仿宋 | 三号 | 右空四字/日期居中于署名之下 |
| 附注（联系人） | 仿宋 | 三号 | 「（联系人：XX 电话：XXXX）」 |

## 字体降级表（本机缺字体时按序取第一档可用）

- 方正小标宋简体 → 宋体 22pt 加粗
- 仿宋_GB2312 → 仿宋 → 隶书
- 黑体 → 微软雅黑加粗
- 楷体_GB2312 → 楷体

降级后在交付说明里注明「按降级表执行」，避免误认为正式排版。

## 表格（附件、议程表用）

三线表：顶线/栏目线 1.5 磅、底线 1.5 磅，无竖线；表头居中加粗；数字右对齐、文字左对齐；跨页重复表头。

## Word 落地映射（office_edit）

先 `office_help {app:"word"}` 核对本机 op。典型顺序：
1. `page_setup`：A4 + 上述边距
2. `style_format`：Normal=仿宋三号+固定行距28磅+首行缩进2字符；Heading 系按上表
3. 写标题段（居中，二号小标宋）→ 主送段（顶格）→ 正文 → 空两行 → 落款（右对齐）
4. 页脚页码若 op 支持则设，否则向用户说明手加位置
5. `office_render` 逐页复核：溢出、半空页、字体替换提醒
