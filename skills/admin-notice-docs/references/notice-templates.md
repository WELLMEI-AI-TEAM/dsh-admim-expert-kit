# 五类文种模板与示例（演示数据均为虚构）

通用骨架：标题 → 主送机关 → 正文（缘由/事项/要求）→ 结尾用语 → 落款（部门+日期）。

## 1. 通知（部署/会议/事务类）

```
关于＋事由＋的通知
各部门、各分厂：
    为＋缘由＋，经公司研究，现就＋事由＋有关事项通知如下：
    一、时间安排
    二、参加对象
    三、活动内容／议程
    四、有关要求
    （一）……（二）……
    特此通知。
    附件：1.报名表（如有）
    联系人：XXX　联系电话：【联系电话】
                     综合管理部
                      2026年11月2日
```

要点：会议通知必写 时间/地点/参会人/材料准备/请假渠道；演练、检查类通知必写 集合点与报到时限；缴费、体检类加「逾期未报视为……」。

## 2. 请示（向上级要钱、要人、要政策；一文一事）

```
关于＋事由＋的请示
XX公司领导：
    （一）请示缘由：现状＋问题＋依据
    （二）请示事项：拟＋具体方案＋预算金额（数字写全）
    （三）实施安排：时间＋责任部门
    以上请示，妥否，请批示。
                     部门名
                      日期
```

忌：一个请示夹两个事项；结尾再提新要求；只说「拟开展」不给预算与时间。

## 3. 通报（表彰/批评/情况）

```
关于＋事由＋的通报
公司各部门：
    （一）基本情况：何时何地何人何事，核查结论
    （二）处理/表彰决定：依据＋结论（引用制度条款号）
    （三）警示/学习要求：各单位要……
    特此通报。
```

要点：批评通报事实部分只写经查实内容，不用推测语气；涉及个人姓名按公司保密要求处理（演示用「张某」）。

## 4. 函（平行或不相隶属单位商洽/询问答复）

```
关于＋事由＋的函
XX公司：
    （一）背景与缘由
    （二）商洽/询问答复事项（分条，明确对方要做的事与回函期限）
    特此函达，请予支持（复函用：已收悉，经研究，答复如下）。
    联系人：……
```

## 5. 启事/通告（面向全员或外部的事务告知：停水停电、搬迁、招领）

```
停水通告
今日14:00—17:00因市政管网检修，公司园区停水。请各部门提前储水，
办公区饮水设备由行政前台统一补给。恢复后如水质浑浊属正常现象。
咨询电话：【联系电话】
综合管理部　2026年11月2日
```

要点：通告语气客观、不要求回复；时间写「今日/明日＋钟点」并用括号补日期。

## 常见组合件

- 通知 + 附件（报名表/议程表）：正文写「附件：1.…」，附件表用 Excel 或 Word 表格页另出。
- 会议通知的议程表列：时间｜议程｜发言人｜时长｜需准备材料。
