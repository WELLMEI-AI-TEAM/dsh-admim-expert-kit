# 办公用品与固定资产台账

以物料主数据和出入库流水核算库存，以一物一卡管理固定资产；交付可继续登记的表，而不是把结存写成一次性数字。

## 选择任务与口径

新建模板、导入旧账、登记流水、盘点、月度汇总按需执行。用户只要办公用品时不强制生成固定资产表。读 [数据结构与公式](references/ledger-schema.md)；盘点与异动时再读 [业务流程](references/inout-stocktake.md)。

从原材料确认物料编号/单位、期初日与数量、统计截止日、流水方向、部门、单价与金额来源。编号保持稳定；同物料不同单位先确认换算率，不直接相加。旧账先备份或写新文件，保留原行与原始单据号；缺失数据作为待核，不能补成0并宣布对平。

## 核算约束

结存 = 期初 + 入库 + 退库 − 领用 − 报损；退库冲减领用净耗用，报损单列。每条流水用唯一编号，数量为正，方向独立；负数与“负数退库”拒绝混用。未识别物料、重复流水、负库存必须给出具体行，不只用颜色提示。

盘点差异 = 实盘 − 账面；正值盘盈、负值盘亏。没有实盘数就是未盘，不按0处理。盘点差异先调查，经审批的调整作为新流水留痕，不能直接覆盖公式或删历史。

耗用金额取流水发生时的单价/已确认计价规则；没有规则或价格则数量核对可继续、金额待确认。不得用今天采购价重算历史领用。折旧仅为行政参考；使用年限、残值率、启用日、财务口径未明确时留空，不默认所有资产残值5%，不把工作量法返回0当已计算。

## 生成或检查

[库存检查脚本](scripts/check.py) 使用 Python 标准库与 Decimal，读取 JSON 后重算数量、流水金额和盘点差异，独立于 Excel。字段与样例见 [接口](references/validation.md)。

```text
python "<本技能目录>/scripts/check.py" "<输入.json>"
```

制作 Excel 用真实单元格范围/结构化表引用，见列规范；动态范围随追加流水扩展，日期按期初日到截止日筛选。金额、结存、补货建议写公式；设置数量/方向验证、低库存条件格式、冻结表头、筛选及打印区。低库存用“低于安全库存”，等于安全库存可另标临界。

生成后读回核对公式、验证和条件格式已写入，并用脚本核算输入样本。openpyxl 不计算公式，不能因读回成功就声称 Excel 已重算；有 Excel/WPS/计算引擎时改一条领用验证联动，否则说明未验证计算与视觉。

交付原文件的新版本、差异/异常清单、统计口径与待确认项。演示行只放单独示例表或示例文件，不混入正式汇总；不自动采购、不生成未经批准的调账。
