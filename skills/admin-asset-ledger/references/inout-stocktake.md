# 出入库流程、盘点与报表口径

## 领用与出库

1. 申请：使用人填「部门+品名+规格+数量+用途」；是否需审批的金额线由公司法务/财务制度定，模板留 `【直领上限：____】` 占位。
2. 出库登记：保管人当日在流水区加行（日期/物料编号/方向=领/数量/领用人/经办人），不直接改结存列——结存是公式。
3. 退库：方向="退"，冲回领用；破损品入「报损」备注并要求说明。

## 月度盘点（每月最后一个工作日）

1. 冻结流水：当日 17:00 后停止出入库登记。
2. 打印盘点表（列：编号/品名/账面结存/实盘数/差异/说明）。
3. 差异处理顺序：先查漏登流水 → 再查跨位置借用 → 仍差异进「盘盈盘亏表」，由行政负责人签核。
4. 盘点后在台账写「盘点基准日」备注，作为下月期初 G 列来源。

## 固定资产年度盘点与贴标

- 编码标签：二维码/条码按公司条件选，无系统时用编号+名称纸质标签。
- 盘点路径：按部门走一圈，核对「保管人与实物一致」，不一致当改 L 列并留异动记录。
- 报废三条件（参照通行制度，按公司制度核）：达年限且功能丧失、维修成本>残值、政策淘汰；走「鉴定—公示—处置」留痕。

## 月度报表口径

| 指标 | 口径 |
| --- | --- |
| 本月领用总额 | Σ(领用数量×当前单价)，单价变过用最近采购价并注明 |
| 部门排名 | 按领用部门 SUMIFS 金额降序，前5通报 |
| 补货建议 | `安全库存×2 − 结存`，正数列示；结合近3月平均消耗量修正 |
| 资产异动 | 本月新增/转移/报废三项，各=COUNTIF 状态或日期列 |

## 演示话术（早会用）

「这是虚构公司10月台账：结存列全是公式——我把『打印机纸』领用从2改成20，整行立刻变红提示补货；汇总看板金额同步变成公式重算结果。」——改一个数，让公式和预警当场动起来。
