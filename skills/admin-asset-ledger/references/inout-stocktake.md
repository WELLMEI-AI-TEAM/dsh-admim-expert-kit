# 出入库、盘点与口径

## 流水登记

领用按公司既有审批额度，不自行设金额线。按原始单据登记独立流水ID、日期、物料ID、方向、正数量、统一单位、部门及发生时单价；保留来源。退库用“退”，报损用“损”，不通过负数量或覆盖期初修正。错误记录用关联更正记录留痕，先核重复单据。

## 盘点

1. 与用户确认盘点日与收发截止点；“每月末17:00”可作示例，不能当公司制度。
2. 锁定该截止点账面快照，盘点期间新增流水单列；未盘物料的实盘数留空。
3. 差异=实盘−账面，正盘盈、负盘亏。先查漏登、重复、跨地点/单位，再分析原因；不能把差异符号直接等同丢失。
4. 原因、审批与调整依据完整后作为后续调整流水；保留原始快照、实盘与调整记录。下一期初来自经确认的期末，不能重复计入本期流水。

## 固定资产

一物一卡、ID稳定。保管人/部门/地点变更记录前后值与生效日；报废要依据公司处置审批，不用“维修费大于残值”自动判废。记录状态与处置日期但不删资产行；二维码或标签只是辅助定位。

## 月度报表

| 指标 | 口径 |
| --- | --- |
| 本期净耗用数量/金额 | 领−退；按本期日期及发生时计价，缺价明确待核 |
| 报损 | 独立数量与金额，不混作正常领用 |
| 部门汇总 | 按流水部门聚合；未填部门单独列未归属，不抹掉 |
| 低库存 | 结存低于安全库存；等于安全库存标临界，负库存先纠错 |
| 补货建议 | MAX(0,目标库存−结存)，目标库存参数可改，必要时结合采购周期 |
| 资产异动 | 按异动记录日期统计新增/转移/报废，不按当前状态推回历史 |

本版脚本检查期末负库存，未验证日内先后与历史时点负库存。要检查时点库存需提供真实流水时间/单据顺序，不能用ID字典序模拟业务先后。
